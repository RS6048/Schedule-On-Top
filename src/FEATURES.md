# 新增功能使用说明

## 一、命令脚本解释器（程序化修改课表）

### 概述
在 `./commands/` 目录下放置后缀为 `.txt` 的脚本文件，程序每次重载课表时会按**文件名升序**依次执行所有脚本，对课表进行程序化修改。

脚本语法类似 Minecraft 命令，每行一条指令，支持变量、四则运算、条件判断、循环、函数递归、时间宏、课表读写和动态添加显示块。

### 文件位置
```
./commands/
  01_friday_exam.txt
  02_afternoon_adjust.txt
  ...
```

### 语法参考

| 命令 | 用法 | 说明 |
|------|------|------|
| `#` | `# 注释内容` | 注释行，整行忽略 |
| `set` | `set $var <value>` | 变量赋值，value 可为数字、字符串、变量或宏 |
| `add` | `add $var <operand>` | `$var = $var + operand` |
| `sub` | `sub $var <operand>` | `$var = $var - operand` |
| `mul` | `mul $var <operand>` | `$var = $var * operand` |
| `div` | `div $var <operand>` | `$var = $var / operand`（整数除，除零为 0） |
| `mod` | `mod $var <operand>` | `$var = $var % operand` |
| `if` | `if $var <op> <value>` | 条件判断开始，支持嵌套 |
| `else` | `else` | 条件分支（可选） |
| `endif` | `endif` | 条件块结束 |
| `while` | `while $var <op> <value>` | 循环开始，支持嵌套 |
| `endwhile` | `endwhile` | 循环结束 |
| `func` | `func <name>` | 函数定义开始 |
| `endfunc` | `endfunc` | 函数定义结束 |
| `call` | `call <name>` | 调用函数（支持递归） |
| `return` | `return` | 从函数返回 |
| `getcourse` | `getcourse <index> $var` | 将第 index 节课的科目存入 $var |
| `setcourse` | `setcourse <index> <name>` | 设置第 index 节课的科目（自动扩展） |
| `replace` | `replace <old> <new>` | 将课表中所有 old 科目替换为 new |
| `addblock` | `addblock <name> <content>` | 添加一个额外显示块（name 仅作标识，content 支持 `$var$` 内联变量） |
| `removeblock` | `removeblock <index>` | 移除第 index 个额外显示块（从 0 开始） |
| `cmd` | `cmd <命令...>` | 异步执行一条 Windows cmd 命令（变量/宏先展开） |
| `mouse` | `mouse <x> <y>` | 移动鼠标到屏幕坐标 (x, y) |
| `click` | `click [x y]` | 左键单击（可先移动到 x,y） |
| `clickright` | `clickright [x y]` | 右键单击（可先移动到 x,y） |
| `key` | `key <名称>` | 按键（ENTER/ESC/SPACE/TAB/F1~F24/A~Z/0~9 等） |
| `type` | `type <文本...>` | 逐字符键入文本（大小写、数字、常用标点；中文不支持） |
| `delay` | `delay <毫秒>` | 暂停两行命令之间的执行（期间可单击幕布立即取消） |
| `run` | `run <文件名>` | 调用 `./commands/` 下的另一个命令文件（共享变量/课表/显示块） |
| `splashscreen` | `splashscreen on [text...]` / `splashscreen off` | `on` 显示全屏幕布并在其上**新增一行**文本（多次 `on` 累积多行）；`off` 关闭幕布并清空新增行 |
| `print` | `print <msg...>` | 控制台输出（调试用） |
| `exit` | `exit` | 终止脚本执行 |

**条件运算符**：`>` `<` `>=` `<=` `==` `!=`（数字和字符串均支持 `==` / `!=`）

### 特殊命令文件（调度规则）
| 文件 | 触发时机 | 说明 |
|------|----------|------|
| `load.txt` | 每次 `reload()` | 自动加载执行，用于初始化变量、设置课表、调用 `run swap.txt` 应用换课 |
| `tick.txt` | 每次更新循环 | 基于 reload 基础上下文**拷贝**独立执行，每次从基准状态开始（`addblock` 不会跨 tick 累积）；防重入（上一次未跑完跳过本次） |
| 其他 `.txt` | 不自动执行 | 需在脚本中用 `run <文件名>` 显式调用，否则忽略 |

### 全屏幕布（splashscreen）
由命令显式控制，不再自动弹出：
- `splashscreen on [text...]`：显示半透明黑色幕布覆盖全屏，并新增一行文本（多次 `on` 累积多行）
- `splashscreen off`：关闭幕布并清空新增行
- 幕布文字："正在调用命令行，请不要操作 / [新增行...] / 目前命令：<当前解释的命令> / 单击幕布取消"
- **目前命令**显示的是当前正在解释执行的命令（所有命令类型，不仅系统命令），
  幕布显示期间每执行一行命令都会刷新
- **鼠标清空圈**：`mouse` / `click` 指令执行前，在目标位置绘制 alpha=0 的透明圆形区域，
  JWindow 忽视 a=0 区域 —— 鼠标在圈内可见、点击穿透到下层窗口，
  因此脚本的 `click` **不会**误触发"单击取消"；鼠标位置由定时器轮询更新
- **单击幕布**（非透明区域）取消当前脚本剩余命令；`delay` 等待期间同样立即生效

### 变量
- 变量以 `$` 开头，如 `$i`、`$course`
- 变量均以字符串存储，运算时自动转为整数
- 多词字符串值会自动拼接，如 `set $msg Hello World` 结果为 `"Hello World"`

### 时间宏
在任意位置使用，执行时自动展开：

| 宏 | 返回值 | 说明 |
|----|--------|------|
| `%date%` | `MM.dd` | 当前日期（如 `08.29`） |
| `%time%` | `HH:mm` | 当前时间 |
| `%day%` | 1~7 | 星期几（1=周一，7=周日） |
| `%dayname%` | 周一~周日 | 星期几中文名 |
| `%month%` | 整数 | 月份 |
| `%dayofmonth%` | 整数 | 日 |
| `%year%` | 整数 | 年份 |
| `%hour%` | 0~23 | 当前小时 |
| `%minute%` | 0~59 | 当前分钟 |
| `%week%` | 整数 | 当前周次 |

`$course$` 宏（`$course$` / 内联 `$course`）：**当前时间对应的课程简称**，用于条件判断与内联文本。按时间表（时间段 HH:mm 成对，与课表一一对应）匹配当前时间所在时段；课间（`|`）、空位（`\`）、自习（`~`）或时段外返回**空串**（非上课），可用 `if $course$ == ""` 判断。示例：
```
# 上课中显示当前科目，课间/自习自动不显示
if $course$ != ""
  addblock 正在上课 当前课程：$course$
endif
```

### 格式化文本
课表、值日生与 `addblock` 显示块支持格式化码（`#` 开头）：

| 代码 | 效果 | 代码 | 效果 |
|------|------|------|------|
| `#cRRGGBB` | 字体颜色（16 进制色码） | `#gRRGGBB` | 背景色（16 进制色码） |
| `#i` | 斜体 | `#b` | 粗体 |
| `#u` | 下划线 | `#d` | 删除线 |
| `#r` | 重置所有格式 | | |

示例（课表文件行）：
```
#cFF0000语 #g00FF00#c000000数 #b英 #i物 #u化 #d生
```
- `#cFF0000语` = 红字"语"；`#g00FF00#c000000数` = 绿底黑字"数"；样式可叠加（`#b#i#u` 同时粗斜下划线）
- 色码不区分大小写（`#cFF0000` / `#cff0000`）；`#c`/`#g` 后不足 6 位色码按普通文本显示
- 格式码可内嵌在课程前（`#cFF0000语`）或独立成 token（`语 #cFF0000 数`）

**计数不受影响**：解析课表（拆分课程、脚本索引、`$course$` 宏、编辑模式）时自动删除所有格式 token，只在最后渲染时应用——格式码不会被当成课程，课程索引与无格式课表完全一致。脚本修改课表后（`setcourse`/`replace`/换课）该行格式会重置为无格式。

### 课表索引说明
课表字符串按空格分隔，索引从 0 开始。例如课表 `语 数 英 | 物 化`：
- 索引 0 = 语
- 索引 1 = 数
- 索引 2 = 英
- 索引 3 = `|`（课间）
- 索引 4 = 物
- 索引 5 = 化

### 显示块说明
程序默认显示三个块：**日期**、**课表**、**值日生**。
使用 `addblock` 可添加额外块，显示在值日生之后。例如：
```
addblock 考试通知 下午物理考试
```
会在课条右侧追加一个"下午物理考试"的显示块。

`addblock` 内容支持 **内联变量**（`$var$` / `$var`）与宏名（`$date$` 等，等同 `%date%`）：
```
addblock 1 today is $date$
# 结果为: today is 09.05
```

### 脚本文件
- 脚本放置于 `./commands/` 目录，后缀 **`.txt`**（旧 `.sscm` 后缀不再支持）
- 仅 `load.txt`（每次 reload）与 `tick.txt`（每次更新）自动执行；其他文件用 `run <文件名>` 显式调用
- `cmd` 命令为异步执行，输出打印到控制台（`[sscm-cmd]` 前缀）
- 键鼠命令需要图形桌面环境（headless 环境不可用）；需要提示时用 `splashscreen on` 显式显示幕布

### 示例

**示例 1：周五添加考试通知并将最后一节设为自习**
```
# 01_friday_exam.txt
if %day% == 5
  addblock 考试通知 下午物理考试 $date$
  setcourse 6 习
  print 周五特殊安排已生效
endif
```

**示例 2：教师节祝福（commands/teachersDay.txt，由 load.txt 调用）**
教师节（9 月 10 日）当天，遍历课表各科并在末尾追加一块祝福，**每一科对应不同祝福语**：
```
if %month% == 9
  if %dayofmonth% == 10
    set $msg 今天是教师节，祝所有老师节日快乐，您辛苦了！
    set $i 0
    while $i < 24
      getcourse $i $c
      if $c == 语
        set $msg 语文老师：春风化雨，润物无声，感恩您的谆谆教诲。 $msg
      endif
      if $c == 数
        set $msg 数学老师：愿您的生活处处是美好解，所求皆所得。 $msg
      endif
      # ……其余科目同理……
      add $i 1
    endwhile
    addblock 教师节祝福 $msg
  endif
endif
```
> 注意：追加 `$msg` 必须写成独立 token（前后加空格），`set` 才将其展开为变量值。

**示例 2：循环打印前 3 节课**
```
set $i 0
while $i < 3
  getcourse $i $c
  print 第 $i 节: $c
  add $i 1
endwhile
```

**示例 3：递归计算阶乘**
```
func factorial
  if $n <= 1
    set $result 1
    return
  endif
  set $tmp $n
  sub $tmp 1
  set $n $tmp
  call factorial
  set $n $tmp
  add $n 1
  mul $result $n
endfunc

set $n 5
call factorial
print 5! = $result
```

**示例 4：将所有体育课替换为自习**
```
replace 体 习
```

**示例 5：单双周不同安排**
```
set $w %week%
mod $w 2
if $w == 0
  setcourse 2 数
else
  setcourse 2 语
endif
```

### 注意事项
- 脚本执行失败（语法错误、索引越界等）仅打印错误日志，**不会导致程序崩溃**
- 多个脚本按文件名顺序执行，共享同一个变量环境和课表上下文
- 课表索引越界时 `setcourse` 会自动扩展课程列表
- 函数支持递归调用，但请注意设置终止条件避免无限递归

## 二、.delay 延迟课表（指定日期覆盖课表）

### 概述
在 `./delay/` 目录下放置后缀为 `.delay` 的文件，用于在**指定日期**完全替换当天显示的课表内容和值日生。适用于考试周、运动会、临时调课等需要预先安排特殊课表的场景。

### 文件位置
```
./delay/
  2026-09-01_exam_review.delay
  2026-10-01_sports_day.delay
  ...
```

### 文件格式
每个 `.delay` 文件为四行纯文本（UTF-8 编码）：
```
第1行：目标日期，格式 YYYY-MM-DD
第2行：创建时间戳（epoch seconds，整数，用于多文件时选最新）
第3行：课表内容（空格分隔的课程简称，与 schedule.txt 格式一致）
第4行：当日值日生（可选，为空则不覆盖原值日生）
```

### 示例
**文件：`2026-09-01_exam_review.delay`**
```
2026-09-01
1756684800
一 数 语 数 | 自 习
值一生
```
含义：2026年9月1日当天，课表显示为 `一 数 语 数 | 自 习`，值日生显示为"值一生"，完全替换掉原本的课表和值日生。

**第四行为空的示例（仅替换课表，不替换值日生）：**
```
2026-09-01
1756684800
一 数 语 数 | 自 习

```

### 匹配规则
1. 程序每次重载时扫描 `./delay/` 目录下所有 `.delay` 文件
2. 读取第1行日期，与当天日期比较
3. 若有多个文件匹配同一天，取**第2行时间戳最大**（最新创建）的文件
4. 若第2行时间戳无法解析，退化为文件修改时间

### 与其他功能的优先级
执行顺序（从先到后）：
1. 正常读取 schedule.txt / saturday.txt / sunday.txt
2. 单双周课程解析
3. 添加自习、晚自习标记
4. **load.txt 脚本执行**（含 `run swap.txt` 命令式换课、`setcourse`/`replace` 等课表修改）
5. **.delay 延迟课表覆盖**（如果当天有匹配文件，完全替换课表与值日生）

即：延迟课表是基础替换；load.txt 的课表修改在 reload 早期生效，延迟课表会在其后覆盖。

### 生成时间戳
时间戳为 Unix epoch seconds（自 1970-01-01 00:00:00 UTC 起的秒数）。
- Linux/Mac 命令行：`date +%s`
- Windows PowerShell：`[int][double]::Parse((Get-Date -UFormat %s))`
- 在线工具：搜索 "unix timestamp"

## 三、快速上手

1. 将编译后的 `.class` 文件和原有配置文件放在同一目录
2. 程序首次运行会自动创建 `./commands/` 和 `./delay/` 目录
4. 在 `./commands/` 中放入 `.txt` 脚本（可参考 `commands/example.txt`）
4. 在 `./delay/` 中放入 `.delay` 文件（可参考 `delay/example.delay`）
5. 右键系统托盘 → Reload，或重启程序使新脚本/延迟课表生效

## 四、MainFrame 课表窗口（v5）

### 双模式布局（【课表】/【设置】）
左侧控制面板为选项卡结构，分为两个模式：

**【课表】模式**（8 列：时间 / 周一~周五 / 周六时间 / 周六）
- **◀ 上一周 / 下一周 ▶**：**真实更改周次**（写入 `.local` 的 `WeekTurn` 并立即生效），
  不再是纯预览；顶部显示当前周次和本周日期范围
- **应用换课**：点击两个课程单元格 → 按钮在 `commands/swap.txt` 追加
  `if %date% == MM.dd + setcourse` 块（命令系统生效）；再次点击同一对可换回
- **第一节课也是真实课程**（行首星期前缀仅 debug），可正常参与换课；课间/空位不可换
- 窗口显示以 **dryRun** 方式模拟执行 load.txt（换课 if+setcourse 生效、系统命令跳过），
  与主课条真实显示一致

**【设置】编辑模式**（6 列：时间 / 周一~周五）
- **只显示周一至周五**：周六与晚自习相关内容不在窗口内显示
  （它们在左侧"周六时段与轮次"/"晚自习轮次"弹窗中编辑）
- **每个课程块都是下拉选择框**：直接在下拉中选择课程即**永久写入**
  `schedule.txt`（无需侧边选择框）；空位/课间为灰色块；显示文件原始内容（不应用脚本）
- **主题色相滑块**：实时预览主窗口主题色，自动保存到 `.local`
- **本地设置**：晚自习开关（`HasNightStudy`）、愚人节彩蛋（`AprilFool`），即时保存
- **添加/移除/编辑课程**：管理 `full_name.txt` 的简称 = 全称条目（下拉框即时刷新）
- **更改时段**：编辑周一至周五课表的时间行（HH:mm 成对，空格分隔）。
  保存后各天课程行自动对齐到新时段数（**类比 Excel 增删列**：加时段自动补空课位 `\`，减时段自动截断多余课程）
- **周六时段与轮次**：编辑 `saturday.txt` 的时间行与周次轮转行，
  轮次行数可自由增删（“+ 添加轮次 / - 删除最后一行”），保存后每行自动对齐时段数
- **晚自习轮次**：编辑 `self_study.txt` —— 第 1 行自习时间（成对 HH:mm），
  其余行按周次轮转（前 6 个 token 为周一~周六自习科目，**末尾为该周次晚自习时间**，如 `19:00 20:00`），
  轮次行数可自由增删
- **命令测试**：打开单测窗口，输入临时 command 逐行运行（基于当前显示上下文复制执行，
  不影响真实课表；`print` 输出与课表修改结果实时显示；`cmd`/键鼠/splashscreen 会真实执行）

### 课表格式说明（重要）
- 所有课表行（`schedule.txt` / `saturday.txt` / `self_study.txt` 轮次行）的
  **第 0 个 token 就是第一节课**（模板中设为“一~六”等星期前缀仅方便 debug，**不是表头**）。
  Frame 网格完整显示所有课程，包括第一节课
- **周六时段单独成一列**：课表模式网格共 8 列 —— 时间 / 周一~周五 / 周六时间 / 周六。
  周六使用 `saturday.txt` 自己的时间行（第 0 行）独立配对显示，
  与周中时间互不相关（示例中两者相同不代表一定相同）
- `saturday.txt` 与 `self_study.txt` 轮次行均按周次取模轮转（行数可动态增减）
- `night_study.txt` 已移除，晚自习时间并入 `self_study.txt` 轮次行末位

### 渲染优化
- 课程单元格（UnitPane）尺寸在构造时确定，`paintComponent` 仅负责绘制，避免渲染循环中反复 setSize
- 圆角矩形 + 选中高亮（柔和主题色填充 + 主题色描边）
- 课表区域支持滚动，表头与网格列严格对齐（课表模式 8 列 / 编辑模式 6 列）

### 命令式换课（if + setcourse）
- **已移除 `swap` 命令**，换课统一用 `if %date% == MM.dd + setcourse 索引 课程` 编写，
  写在 `./commands/swap.txt`，由 `load.txt` 每次 reload 自动 `run swap.txt` 调用
- 索引从 0 开始：0=第一节（行首星期前缀是第一节课，不是表头）

  用户手写 swap.txt 与按钮操作互不冲突
